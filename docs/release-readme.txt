Dharma Dojo - English translation {version}
=============================================

Unofficial English fan translation of Dharma Doujou (SNES, Metro, 1994), a falling-block puzzle game.
This zip holds only a patch. It contains no game data; you need your own dump of the Japanese cartridge.

Base ROM (No-Intro: Dharma Doujou (Japan))

  Size:   {size} bytes (no copier header)
  CRC32:  {crc}
  MD5:    {md5}
  SHA-1:  {sha1}

Patched ROM
  CRC32:  {pcrc}
  SHA-1:  {psha1}

How to patch
  Apply {patch} to the base ROM with any BPS patcher: Flips, beat, or RomPatcher.js
  (https://www.marcrobledo.com/RomPatcher.js/). The patcher refuses a ROM that isn't the one above.
  If your file is 1,049,088 bytes it has a 512-byte copier header: remove it first.

Play
  Tested in Mesen 2.2.1 (MesenCE). Start the game from a cold boot (power on), not from a savestate made with
  the Japanese version.

What's translated
  All dialogue, menus, the tutorial, quiz questions, story scenes, credits, and the Japanese text drawn as
  graphics (title logo, banners, HUD, pause plates, certificates).
  Kept as in the original: the small 千両 ("a thousand ryo") label on the treasure-chest puzzle piece, which is
  part of the piece's picture.

Known issues
